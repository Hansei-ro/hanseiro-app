# 🚖 Hansei-ro (한세로)

> 한세대학교 학생들을 위한 택시 동승 매칭 및 실시간 셔틀버스 정보 플랫폼  
> **"Simple, Secure, Resilient"** - 단순한 구조, 강력한 보안, 견고한 사용자 경험

## ✅ 빠른 시작

```bash
yarn install
```

```env
EXPO_PUBLIC_API_URL=http://localhost:3000
```

```bash
yarn start
```

> ⚠️ 이 프로젝트는 네이티브 모듈을 사용하므로 **Expo Go와 호환되지 않습니다**.  
> 실제 기기/에뮬레이터 실행은 `docs/SETUP.md`를 참고하세요.
